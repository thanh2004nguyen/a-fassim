# Escape from Blackwood Forest

A text based adventure game written in Python for a programming course assignment.

## How to run

```bash
python3 text_adventure_game.py
```

Enter a name (3-15 characters, letters, numbers or underscores), then type the
number of your choice at each step. Results are saved to `game_results.json`.

## Files

- `text_adventure_game.py` - the game
- `text_adventure_game_submission.txt` - submission file with code, sample run and references
- `huong_dan_viet_code.md` - step by step walkthrough of the code (Vietnamese)
